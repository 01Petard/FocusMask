# FocusMask

**简体中文** · [English](README.en.md)

让每个网页由你掌控。FocusMask 是一个 Chrome / Edge 扩展，可隐藏干扰元素、模糊图片与视频、模糊整页。配置和规则只保存在本地。

当前版本：**0.1.2**。扩展界面提供简体中文和英语；默认跟随浏览器语言，简中、繁中均使用简体中文，其他语言使用英语。小窗和设置页都可手动切换。

## 安装与更新

1. 使用 Node.js 24+、pnpm 10.34.6，在项目目录执行：

   ```sh
   pnpm install --frozen-lockfile
   pnpm run verify
   ```

2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择「加载已解压的扩展」，加载本项目的 `dist` 目录。
3. 已安装版本更新后，先在扩展管理页点击 FocusMask 的「重新加载」，再刷新原有网页。**只刷新设置页不会更新后台或原有网页脚本。**配置和规则会保留。

发布包通过 `pnpm run package` 生成，路径为 `release/focusmask-0.1.2.zip`。本项目不会自动上传商店或发布。

## 从当前网页开始

打开普通 HTTP / HTTPS 网站，点击工具栏里的 FocusMask 图标，再点击「启用此网站」并确认授权。三个模式默认关闭，按需开启：

| 模式 | 效果 | 恢复方式 |
| --- | --- | --- |
| 元素过滤 | 用保存的选择器隐藏网页元素，不删除 DOM | 关闭模式、禁用或删除规则 |
| 媒体模糊 | 对图片和 HTML5 视频应用 16px 高斯模糊，保留布局尺寸 | 点击或悬停临时显示 |
| 整页模糊 | 用全屏高斯背景模糊保护页面，提供查看入口 | 临时显示，或切换关闭整页模糊 |

「选择网页元素」进入选择模式。选中元素后预览隐藏效果；匹配多个元素时需要确认。保存后刷新仍会应用，Esc 或取消恢复未保存的预览。保存后的撤销只删除刚新增的规则。

浏览器内部页、扩展页和商店等受限制页面不能应用这些操作，小窗会给出明确提示。

## 临时查看与快速开关

在「临时显示方式」中选择点击或悬停。点击立即显示；默认悬停满 **250ms** 才显示，提前移开会取消。查看后默认 **1000ms** 自动恢复模糊。没有「重新模糊」按钮；再次悬停查看前先移开鼠标。

整页临时显示不会移除元素过滤或媒体模糊。SPA 路由切换保留剩余计时；刷新、新文档或标签隐藏会重新保护。媒体更换资源后重新模糊。

快速整页开关默认为 `Ctrl+Shift+Y`，macOS 为 `Command+Shift+Y`。再次按键关闭当前文档的整页保护，工具栏的「启用整页模糊 / 关闭整页模糊」行为相同。**切换关闭后不会因计时或标签切换自动启用**；刷新后重新遵循网站持久配置。未永久授权的普通网页也可通过主动按键使用一次性保护，不创建网站配置。

设置页展示实际快捷键绑定，并提供浏览器快捷键管理入口。快捷键失败时工具栏会显示 `!`；旧版网页脚本需要刷新时会提示刷新。

## 通用设置与网站管理

小窗或设置页的语言菜单提供「跟随浏览器 / 简体中文 / English」。选择会保存在本地，并同步到扩展页面和已经注入的网页控件，不改变原网站的语言。

时间设置统一使用毫秒，修改后点击「保存时间设置」：

| 设置 | 默认值 | 可设置范围 |
| --- | ---: | ---: |
| 自动恢复模糊 | 1000 | 100–600000 |
| 悬停触发延迟 | 250 | 0–10000 |
| 提示显示时长 | 5000 | 500–60000 |
| 撤销操作时长 | 12000 | 1000–300000 |
| 开关动画时长 | 100 | 0–1000 |

网站按精确 Origin 分开保存，包括协议、主机和有效端口。全局开关、网站开关和对应模式开关共同控制持久效果。

- 全局暂停：清除效果和临时状态，保留配置；恢复后重新应用持久设置。
- 恢复网站全部视觉修改：关闭网站开关，保留模式、规则和授权。
- 恢复全部元素：关闭元素过滤，保留规则。
- 删除网站：删除配置和规则，并尝试撤销不再被其他配置依赖的对应授权。

## 开发与验证

项目通过 `packageManager` 固定 pnpm 10.34.6，仅维护 `pnpm-lock.yaml`。

```sh
pnpm run lint
pnpm run typecheck
pnpm test
pnpm run build
pnpm run verify
pnpm run package
```

`pnpm run dev` 只预览 Vue 页面。网页操作、权限和持久化需在加载后的扩展中验证。

真实浏览器测试使用独立临时配置和本地测试页：

```sh
pnpm exec playwright install chromium
pnpm run test:browser
```

默认显示测试浏览器，原生授权提示可能需要人工确认。可通过 `FOCUSMASK_BROWSER_EXECUTABLE` 指定可执行文件，`FOCUSMASK_HEADED=0` 使用无界面模式。

Edge 页面测试提供预授权夹具：

```sh
FOCUSMASK_TEST_LABEL=edge FOCUSMASK_PREGRANT=1 \
FOCUSMASK_BROWSER_EXECUTABLE='/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge' \
pnpm run test:browser
```

夹具只修改临时测试副本，不修改发布权限；它不能证明 Edge 原生授权、拒绝和撤销流程通过。详细证据和未验证项目见[验证记录](doc/verification.md)。

## 范围与限制

- 只处理顶层普通 HTML 文档；不覆盖 iframe 内部、网站 Shadow DOM、CSS 背景图、Canvas、PDF 和特殊页面。
- 模糊只改变视觉呈现，不阻止下载、网络请求或音频播放，也不是密码锁。
- 尽早应用导航保护，但不承诺所有加载路径绝对零闪现。
- 扩展被浏览器禁用后，如原页面仍残留效果，刷新页面即可恢复。
- 不隐藏地址栏、标签标题、浏览历史、网络流量或系统预览。
