# 界面约定

**简体中文** · [English](DESIGN.en.md)

FocusMask 的界面以清晰、安静和可恢复的操作为目标，使用暖白底、深灰文字和克制的森林绿。系统字体包含中文回退，不加载远程字体或素材。

- 工具栏小窗宽 350px，上方品牌和设置入口，接着是当前网站、状态、模式和快捷操作。限制高度并允许滚动；不支持页面使用明确的空状态，不展示误导性的网站状态和规则数量。
- 设置页使用可读的 16px 正文、14px 辅助文字和清晰的标题层级。网站列表与详情相邻，窄屏改为单列。时间输入统一显示毫秒单位。
- 语言和临时显示方式采用自定义下拉列表。选中项持续回显；键盘支持方向键、Home、End、Enter、Escape 和 Tab。所有主要控件有明显焦点状态。
- 当前操作显示处理中、成功或失败反馈。网站恢复、元素恢复与删除保留各自语义。
- 网页内整页界面使用透明顶层表面与高斯背景模糊；媒体入口覆盖已模糊的源元素。Shadow DOM 隔离控件样式；语言变更不修改源网页语言。
- 小窗、设置页和网页内控件共用完整的中英文文案。配置页右下角提供作者链接；语言菜单提供自动、简体中文和英语。
