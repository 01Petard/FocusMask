# 隐私声明

**简体中文** · [English](PRIVACY.en.md)

适用于 FocusMask 0.1.2。扩展不提供账号、后端服务、云同步、遥测或数据分析，不调用第三方服务。

## 本地数据

`chrome.storage.local` 保存网站 Origin、模式开关、元素选择器规则、界面语言和时间偏好。临时显示状态只存在当前网页内存中，不跨标签共享，也不会同步到云端。

为应用视觉规则，扩展处理目标网页的 DOM 结构、元素位置和媒体尺寸。它不读取密码或表单输入值，不记录完整 HTML、浏览日志或浏览历史，不上传网页或规则。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存本地配置与规则 |
| `scripting` | 注入扩展内打包的脚本与样式 |
| `activeTab` | 用户主动触发时操作当前标签页，例如快速整页模糊 |
| 可选 HTTP / HTTPS 网站权限 | 仅在用户授权后为相应网站自动应用保存的设置 |

快捷键通过 Manifest 的 `commands` 字段声明，不额外申请同名权限。扩展不包含远程执行代码。

## 管理与删除

你可以关闭单个模式、暂停扩展、删除规则，或删除网站配置并撤销不再被其他配置依赖的对应授权。浏览器控制实际授权；撤销失败会反馈错误。卸载扩展时，扩展存储由浏览器清除。

设置页右下角的作者链接由你主动打开，前往 GitHub；扩展不会自动向该地址发送数据。

## 保护边界

隐藏和模糊只改变页面视觉呈现，不阻止网络传输、媒体下载或音频播放。它们不提供密码锁，也不隐藏地址栏、标签标题、历史记录或操作系统预览，不能替代浏览器、网络和系统安全措施。
