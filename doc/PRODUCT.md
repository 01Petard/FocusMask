# 产品行为与范围

**简体中文** · [English](PRODUCT.en.md)

FocusMask 0.1.2 面向 Chrome / Edge Manifest V3，完成「授权网站 → 配置模式 → 隐藏或模糊 → 保存规则 → 再次访问应用 → 随时恢复」的本地使用闭环。

## 三种模式

元素过滤使用 CSS 隐藏规则命中的元素，保留源站 DOM；媒体模式使用高斯模糊处理图片和 HTML5 视频，不替换资源地址或包裹元素；整页模式使用顶层界面和全屏高斯背景模糊提供临时查看入口。

新网站的三个模式默认关闭，授权本身不修改网页。模式独立开关，持久效果同时受全局开关、网站开关和模式开关控制。

## 状态与交互

- 临时查看选择点击或悬停。默认悬停延迟 250ms，自动恢复 1000ms；提示、撤销和开关动画时间同样可配置。没有重新模糊按钮，查看按钮不附带时间文字。
- 临时显示仅影响当前文档，不写入持久配置。SPA 路由不重置剩余计时；刷新、新文档和标签隐藏重新保护。
- 快速整页开关是双向切换，关闭后取消临时恢复，不因标签切换再次保护；新文档重新遵循保存的网站设置。
- 全局暂停清除效果和临时状态，恢复时重新应用持久配置。
- 网站恢复关闭网站开关，元素恢复关闭元素过滤，两者均保留规则。删除网站才删除配置和规则，并处理对应授权。

## 设置和语言

网站按规范化的精确 Origin 存储，区分协议、主机和有效端口。后台串行写入配置，授权状态从浏览器实时查询。

界面语言默认跟随浏览器，简中和繁中显示简体中文，其他语言显示英语；浏览器接口不可用时使用系统提供给页面的语言。用户可在小窗或设置页手动选择简体中文、英语或自动，并保存在本地。切换同步到已打开的扩展界面和网页内控件，不修改原网站语言。

语言和查看方式使用自定义下拉列表，保留全部选项与当前选中值，支持键盘操作。设置页右下角提供作者 GitHub 链接。

## 工程边界

Vue 3 + TypeScript + Vite 用于扩展页面；页面处理为原生 TypeScript 隔离 Content Script。后台负责权限、配置、动态注册和命令。页面控件采用 Shadow DOM；只处理顶层普通 HTML 文档。

无后端、账号、同步、网络拦截、AI 分类、复杂 iframe、源站 Shadow DOM、背景图片或 Canvas 过滤。不承诺绝对零闪现。商店上传与正式发布单独执行。
